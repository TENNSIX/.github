
- [Scalar](https://github.com/TENNSIX/Scalar) is the master project for scalar classes.
- [Tennsix](https://github.com/TENNSIX/Tennsix) is a project serving linear algebra based on Scalar types. 

These projects were created in 2021-2022. They have been largely inactive since 2023 but have been resurrected recently.
